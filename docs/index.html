Verificação de certificado

Digite o código impresso no certificado ou leia o QR code.

O código está no rodapé do certificado. Ao ler o QR code, a verificação é feita automaticamente.

Privacidade

Esta página só mostra um certificado a quem informa o código dele: nome, tipo de certificado, startup (quando houver) e o link do PDF. Os registros ficam cifrados, e sem o código não é possível ler nem listar quem participou. A verificação acontece no seu navegador e o código não é enviado a nenhum servidor.

Os dados são usados apenas para emitir e comprovar os certificados do evento (LGPD, Lei 13.709/2018). Para corrigir dados ou pedir a remoção do seu certificado, fale com a organização: switapema@gmail.com.
